# b.l.a.d.e. dice

Mobile-first web game: tap **b.l.a.d.e.** and two 3D dice fall, showing a trick combination for the BLADE game. The **Mode** tab is the main page for choosing a game mode (Classic 2 dice and In-Grind-Out 3 dice are playable, the others are coming soon). The Mode/Game/Rules menu appears only after a mode is chosen. The **Rules** tab has the rules and dice lists in Ukrainian (UA) and English (ENG).

## Files
- `index.html` - page structure (Game and Rules tabs)
- `style.css` - styles, light and dark themes
- `script.js` - dice, animation and tab logic

## Run
Open `index.html` in a browser, or serve the folder (for example with GitHub Pages).
