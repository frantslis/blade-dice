# b.l.a.d.e. dice

Mobile-first web game: tap **b.l.a.d.e.** with two 3D dice fall, showing a trick combination for the BLADE game. The **Rules** tab has the rules and dice lists in Ukrainian (UA) and English (ENG).

## Files
- `index.html` - page structure (Game and Rules tabs)
- `style.css` - styles, light and dark themes
- `script.js` - dice, animation and tab logic

## Run
Open `index.html` in a browser, or serve the folder (for example with GitHub Pages).
